课堂贯穿示例：100 万条设备工单里，查“设备反复高温报警”

贯穿例子：在历史设备工单里找相似处理方案

假设系统里有 100 万条历史工单，每条工单都已经被 embedding 模型转成向量。

用户查询：设备反复高温报警，应该先检查什么？
1. 文本变向量 把查询语句变成一个向量 Q，含义相近的工单向量会离 Q 更近。
2. 索引缩小范围 索引不是直接生成答案，而是帮系统少扫数据、更快找到候选工单。
3. 找 Top-K 返回最相似的几条历史工单，比如过载、散热、传感器异常。
4. RAG 生成答案 大模型基于这些工单证据，总结排查步骤和升级条件。
蓝点 = 历史工单向量
红点 Q = 当前查询
绿点 = 找到的相似工单
黄点/码本 = 索引结构
